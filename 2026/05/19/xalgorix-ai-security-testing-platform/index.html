📌 项目概述

Xalgorix 是一个开源、自托管（self-hosted）的 AI 安全测试平台，旨在结合 大型语言模型（LLM） 与 传统安全测试工具，为授权的渗透测试与漏洞挖掘工作流提供一整套自主、自动化的解决方案。

⚠️ 重要声明：本平台仅适用于合法授权的安全测试场景。请确保在使用前获得目标系统所有者的明确书面授权。

该平台适用于：

  • 🔒 安全研究者与红队工程师
  • 🦸 白帽黑客与漏洞赏金（Bug Bounty）参与者
  • 🏢 企业安全团队的自动化测试需求

🧠 核心功能

✔️ 自托管 Web UI

本地 Web 仪表盘默认运行在 127.0.0.1:9137，提供：

  • 🚀 启动与控制扫描任务
  • 📊 实时监控扫描进度与事件流
  • 🔍 查看漏洞详情与攻击证据
  • 📄 生成定制化 PDF 报告

🤖 多模态扫描模式

模式 说明
Single Target 针对单一 URL 或主机执行全流程渗透测试
DAST 基于浏览器的动态应用测试，覆盖认证流程、表单注入、运行时行为分析
Wildcard / Multi-Target 扫描所有子域名及相关资源，适用于攻击面发现与资产梳理

📊 22 阶段测试方法论

Xalgorix 将渗透测试拆解为 22 个逻辑阶段，覆盖完整攻击链：

阶段 测试内容
1-3 信息收集、端口扫描、服务识别
4-6 认证测试、会话管理、权限绕过
7-10 注入攻击（SQL/XSS/Command）、文件包含
11-14 暴力破解、字典攻击、密码策略测试
15-18 业务逻辑漏洞、API 安全、中间件配置
19-22 漏洞验证、证据收集、报告生成

用户可在 Web UI 中选择全部阶段或指定阶段以灵活调整扫描策略。

🔬 源代码原理与架构

模块组成

模块路径 功能说明
cmd/xalgorix 程序入口及 CLI 命令解析
internal/ 核心逻辑：扫描调度、LLM 协调器、事件流处理
webui/ React 前端，构建 Web 控制界面
docs/ 文档、方法论与使用说明
assets/ 图标、静态资源

工作原理核心

  1. LLM 作为自主测试引擎 — 将大型语言模型作为智能决策核心，指挥传统安全工具执行任务并分析结果
  2. 实时事件流 — 扫描期间，所有工具调用、LLM 推理、发现事件通过 WebSocket 实时推送至前端
  3. 工具自动安装与调用 — 内置 Nmap、SQLMap、Nuclei 等工具，缺失时自动下载执行
  4. 结构化扫描流程 — 22 个阶段序列化任务，每阶段结果整合至扫描日志，作为报告与发现索引基础

📌 总结

Xalgorix 是一个功能全面、自动化程度高的开源 AI 驱动渗透测试平台。它创新性地将传统安全工具（Nmap、SQLMap、Nuclei 等）与 LLM 智能分析相结合，配合实时监控与报告生成机制，为安全团队提供高效、可扩展的工作流。

无论是独立安全研究者还是企业安全团队，都可借助 Xalgorix 显著提升安全测试效率与覆盖深度。
